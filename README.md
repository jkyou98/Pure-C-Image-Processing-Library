# Pure C Image Processing Library

This is Image Processing Lib writing by pure C 

Including following work:
1. Contrast Enhancement: CLAHE, Histogram Equaliztion  
2. Noise Removal: Mean Filter, Outlier Noise Removal 
3. File Read/Write: BMP, RAW (for data over 8 bit)
4. Other: Brightness Normalization, Image Convolution Border Setup, Gaussain Blur
